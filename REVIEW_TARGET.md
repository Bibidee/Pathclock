# 5/5 review target map

This file is a build target, not a claim that any reviewer must award a particular score.

## GenLayer fit target

The consequential question is semantic: whether a candidate release satisfies a frozen security-remediation requirement. The developer cannot fairly self-certify it and the requester cannot fairly veto it. A normal deterministic oracle cannot derive the answer from one number. GenLayer consensus produces the neutral decision that gates release authority.

## Contract-quality target

- three real trust boundaries, not decorative file splitting;
- validator independently fetches the committed evidence;
- validator compares decision-bearing substance;
- REMEDIATED requires every material check true;
- explicit uncertainty and hostile-evidence handling;
- evidence digest/manifest persisted;
- irreversible consequence deferred to a finality-triggered child message.

## Engineering target

- pinned toolchain;
- lint/schema/direct/unit/CI paths;
- immutable deployment manifest;
- canonical demo fixture;
- network verification script;
- source digests;
- failure-path checklist;
- no runtime-loader imports in `conftest.py` because there is no `conftest.py`.

## Frontend/UX target

- only four routes;
- clean-room design unrelated to earlier `ometere123` frontends;
- security-review concepts rather than raw ABI concepts;
- accepted is explicitly provisional;
- final-state reread and authority presence determine completion;
- public proof works without wallet;
- mobile composition avoids tables/sidebar squeezing.
