# PATHCLOCK canonical demo fixture

This is a deliberately tiny, synthetic security-remediation fixture for the live PATHCLOCK proof. It exists so reviewers can understand exactly what GenLayer is judging without relying on a private repository or unstable third-party page.

The vulnerable baseline returns privileged account state before rejecting an expired session. The candidate reverses that ordering and the regression evidence binds the test and deployment identity to the candidate commit.

The finishing agent should publish this repository, then use immutable commit-pinned **raw GitHub URLs** generated by `scripts/demo_urls.py`. Do not use mutable `main` URLs for the canonical review.
